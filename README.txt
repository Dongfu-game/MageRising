MageRising 스킬 리뉴얼 테스트 버전 (원본 MageRising-main.zip 기준)

이 ZIP은 게임 전체가 아닌 변경된 파일만 포함합니다. 기존 게임을 백업한 별도 테스트 복사본에만 덮어써 주세요. 기존 저장 데이터는 반드시 게임 설정의 저장 파일 내보내기로 백업하세요.

땅, 바다(코드 이펙트), 하늘, 마나, 초월 계열로 변경했습니다. 마나 자원 소모/충전과 초월 슬롯 분리는 포함되지 않습니다. 마나 특성은 마력 증폭만 사용 가능하며 나머지는 다음 단계까지 잠겨 있습니다. 바다의 위력은 테스트용 임시 수치입니다.
기존 마법사 저장은 땅 계열 스킬만 보존하고 나머지 스킬은 초기화해 SP 재배분을 시도합니다. 초월 투자 및 장착도 초기화됩니다. 원본 저장의 백업을 생성하는 코드가 포함되어 있으나 실제 사용자 저장으로 검증하지 않았습니다.
검증: JavaScript 문법 및 스킬 트리/레벨/시너지/내성 코드 검사만 진행했습니다. 실제 브라우저 실행, 전투, 시각 효과, 저장 이전, 다른 직업은 검증하지 못했습니다. 라이브 GitHub Pages에 곧바로 업로드하지 마세요.
