MageRising v0.9.21 — 보스 특성 / 호위병 조건 / 해골왕 군단

적용: v0.9.20 기준. index.html, sw.js, js/game.js를 같은 경로에 덮어쓰기. 나머지 파일 유지. 새 이미지 파일 불필요. 저장 데이터 초기화 불필요.

보스 공통
- 서로 다른 특성2개. 일반 단계 보스는 근접/원거리/순간이동/버프 중 랜덤2개.
- 10단위 보스는 버프+랜덤1개. 고정형50/100 해골보스는 버프+근접 또는 원거리.
- 이동형 보스만 기존66→99(1.5배). 고정형 위치 유지.
- 버프 보스는 같은 스테이지 일반 적 전체에 기존 버프 효과/주기 적용.
- 일반 단계 보스 출현 시점은 기존대로 일반 적 목표 완료 후.

10단위 스테이지
- 보스는 처음부터 등장. 일반 적 처치 목표의10%(올림)까지 무적.
- 일반10단위 보스는 버프만 제공하고 이동/공격/순간이동 대기. 조건 달성 후 참전.
- 50/100 해골보스는 무적 중에도 기존 고유 공격 실행. 100단위 왕은 군단도 소환.
- 무적 보스는 조준/투사체 충돌/피해/제어 대상에서 제외. 뒤 일반 적을 정상 공격.
- 일반 적 목표와 보스 처치를 모두 완료해야 클리어.
- 보스 위/오른쪽 상단에 특성과 무적 해제 처치량 표시.

해골왕: 기존98/99단계 보스 소환을 언데드로 교체
- 전투 시작 시 데스나이트1마리 / 해골마법사1마리. 각 전투당1회만, 사망 후 재소환 없음.
- 해골전사5초마다3마리. 동시 생존 최대12마리. 초과분 적립 없음.
- 해당 스테이지 일반 적HP 기준: 전사1배, 마법사2배, 데스나이트6배.
- 기본 적 공격력 기준 전사0.6배 / 마법사0.8배 / 데스나이트1.5배. 데스나이트 방어력1.5배.
- 마법사는 후방 원거리 투사체, 데스나이트와 전사는 전진 근접 공격.
- 소환술사 기존 이미지 재사용+적군 분홍색 오라/HP바. 이미지 로딩 전 단순 형태 대체 표시.
- 소환수는 일반 적 목표/무적 해제/골드/SP/조각/카드 보상에 포함하지 않음.
- 왕 사망 시 모두 소멸.

저장
- 보스 특성, HP비율/위치/공격 대기, 일회용 소환 사용 기록, 살아 있는 언데드HP/위치, 전사 소환 대기를 저장.
- 기존 저장에는 새 기록이 없으면 최초 생성 시 특성 결정. 기존 배운 스킬/장비/진행은 보존.
- 사망 후 재도전은 새 전투이므로 소환 사용 기록 초기화.

검증
- 기존 회귀11,120개 통과. 검사 방어/콤보 검사 통과.
- 1~200단계 보스 특성 조합, 속도, 10%경계, 무적 피해/기절 방지, 해골보스 대기중 공격, 군단 상한/일회용/무보상/왕 사망소멸 검사.
- 저장 검증/재접속 복원/중복 특성 거부/4직업 보호 대상 제외 검사 통과.
- 10/50/100단계 캔버스 렌더링 확인. 실제 휴대폰/장기 전투 밸런스는 미검증.
