마법사의 여정 · Mage Rising v0.4.1
================================
SKILL SYSTEM 2.0: 14 액티브 + 9 패시브 / 3슬롯 자동시전

실행: 압축 해제 → START.html을 Acode 미리보기 또는 브라우저로 열기.
START.html은 CSS·JS·스킨 이미지가 모두 들어 있는 단일 실행 파일입니다.
Android content:// 방식으로 파일 하나만 열어도 스킨 이미지를 읽을 수 있도록 내장했습니다.
index.html은 assets/skins/ 상대경로에서 이미지를 읽으므로 전체 폴더를 함께 보관하세요.
편집: index.html + style.css + js/config.js, items.js, skills.js, game.js.

마법 특성·범위·내성·자동시전이 바뀌어 실전 처치 시간까지 같지는 않습니다.

해금
- 기본 계열: 바로 앞 노드 투자 Lv.1 + 마력 강화 10/30/50/100.
- 첫 액티브 제한 없음. 기존에 배운 스킬은 마력 조건 미달이어도 유지.

시너지
- 1단계 → 2단계 +3%/Lv, 3단계 +2%/Lv.
- 2단계 → 1/3단계 각각 +3%/Lv.
- 3단계 → 1/2단계 각각 +2%/Lv.
- 기본 계열 3액티브 모두 마스터 시 각 피해 +50%. 초월 제외.
- 피해 = 기존 계산 × (1 + 시너지 합계 + 해당 계열 세트 피해 보너스).
- 장착 여부 무관. SP 투자 레벨만 시너지/해금 판정에 사용.

세트 5종 (유니크 동급, 동일 기본 성능 및 랜덤 옵션/부위 고유능력)
- 아폴론의 광휘 / Radiance of Apollon: 에너지
- 하데스의 업화 / Hellfire of Hades: 화염
- 포세이돈의 동토 / Tundra of Poseidon: 냉기
- 제우스의 격노 / Wrath of Zeus: 번개
- 크로노스의 종말 / Doom of Chronos: 초월
- 2부위: 해당 계열 피해 +10%.
- 3부위: 아폴론 범위 +10%, 하데스 화상 지속 +1초, 포세이돈 둔화/빙결 지속 +15%, 제우스 시전시간 감소 +5%p, 크로노스 쿨감 +5%p.
- 4부위: 해당 계열 액티브 +1레벨.
- 5부위: 아폴론 관통 페널티 3%p 완화, 하데스 화상 피해 +25%, 포세이돈 파쇄 피해 +25%, 제우스 추가 도약 +1명, 크로노스 초월 범위 +20%.
- 6부위: 추가 +1레벨(누적 +2), 7부위 추가 +3레벨(누적 +5).
- 화상/냉기 지속/관통/파쇄/도약 특화 효과는 관련 패시브 필요.
- 투자 Lv.10 + 세트5 = 적용 Lv.15. 기존 피해/지속시간/연쇄 등 레벨별 성장 계속 적용.
