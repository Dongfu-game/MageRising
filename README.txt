검사 방어 계열만 변경. 기존 최대 레벨, SP 비용, 선행 조건, 투자 레벨 유지(총70SP).
현재 소스 순서: 막기10×1SP / 철벽5×1SP / 반격10×2SP / 호흡5×1SP / 절대방어10×3SP.

막기: 습득 후 자동. 확률30% + 추가 유효레벨당4%p(최대75%). 성공하면 방어·카드 감소 후 피해50% 감소.
반격: 막기 성공 시 자동. 기존 피해계수와 레벨별15% 성장 유지. 계열 투자 시너지 삭제. 0.3초 발동 제한. 기존 근접3번칸 범위 판정. 콤보 증가·공격 순서 간섭 없음. 실제 전투 통계에 별도 집계.
절대방어: 피격 후 살아남은 HP가 최대HP30% 미만이면 자동. Lv1 1초~Lv10 2초 무적, 20초 재사용 대기(발동 순간부터, 쿨감 제외). 발동 공격은 먼저 받으며 치명적인 공격은 구해주지 않음. 무적 중 콤보와 회복 유지. 재사용 대기 후 낮은HP 상태에서 다시 피격되어도 발동.
철벽/호흡: 기존 효과 유지.
모두 슬롯 불필요. 기존 장착된 방어 스킬만 슬롯에서 해제하고 배운 레벨/SP는 보존. 방어 스킬만 장착되어 있었다면 일자베기 하나를 자동 배치.
방어 계열 투자 시너지 제거. 다른 공격 계열 시너지 유지.

자동 검사: 막기 감소량, 자동 반격/발동 제한/통계 귀속, 무적 지속/재사용/치명타격 예외, 기존 저장 슬롯 이전, 총70SP 보존, 콤보 회귀 검사 통과. 실제 휴대폰 검증 미실시.
