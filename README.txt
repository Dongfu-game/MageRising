MageRising v0.9.19 — 검사 콤보와 지면 연출

적용: ZIP의 index.html, sw.js, js/game.js, js/warrior-fx.js를 기존 저장소의 같은 경로에 덮어쓰세요. 기존 v0.9.18 파일들은 유지합니다. 저장 데이터 초기화는 필요하지 않습니다.

검사: 베기·찌르기·내려찍기 계열 공격 스킬 2종 이상 장착 시 콤보가 작동합니다. 해당 공격 스킬은 중복 슬롯 장착을 지원하며 슬롯 순서대로 공격합니다. 첫 공격만 기존 시전 준비를 거치고 다음 공격부터 짧은 회복 간격으로 연계합니다. 다단 공격은 기존 타격 간격을 유지합니다. 적중한 공격 동작마다 콤보 1회 집계, 1.5초간 사거리 내 대상이 없으면 초기화합니다. 방어 스킬은 콤보 연계 대상에서 제외됩니다. 우측 상단 콤보 표시와 단계별 색상을 추가했습니다.

피해 배율 보너스는 없지만 공격 간격 단축으로 실제 초당 피해는 증가합니다. 캐릭터 창의 기준 DPS는 기존 계산이므로 콤보 효과 확인에는 실제 전투 통계를 사용하세요.

연출: 내려찍기 전진 충격파, 대지 분쇄 전방 지면 함몰, 지진은 기존 마법사 화면 균열 재사용. 모든 맵에 분위기에 맞는 바닥을 추가했습니다. 지면은 시각 효과이며 이동·판정은 바꾸지 않습니다.

검증: 기존 회귀 검사 11,122개 통과. 중복 슬롯 저장 검증, 슬롯 연계 순서, 광역 1회 집계, 대기 중 초기화, 다른 직업 중복 금지 검사 통과. 3개 맵에서 9개 효과 렌더링 확인. 실제 휴대폰 확인은 미실시.
