Mage Rising v0.9.28 — 다수의 적 전투 중복 계산 최적화

v0.9.27 게임 루트에 ZIP 파일 내용을 같은 경로로 덮어쓰고 새로고침하세요.
포함: index.html, sw.js, js/game.js, 안내문.

수정
- 같은 전투 계산 또는 화면 그리기 작업 안에서 캐릭터 능력치를 재사용합니다.
- 장비 조각 지급/보스 장비 보상/카드 변화 시 캐시를 무효화해 성장 수치를 즉시 반영합니다.
- 피격과 처치 골드 계산에서 불필요한 전체 스킬 DPS 계산을 제거했습니다.
- 슬롯 상태/DPS UI를 매 프레임 갱신하는 부담을 줄였습니다.
- 적 수, 공격 주기, 피해량, 보상, 실제 전투 시뮬레이션 주기는 유지합니다.

검증
- Chromium, 113단계, 적 54마리, Rock Shot/Stone Shower/Earthquake 조합, 동일 난수 조건에서 수정 전후 비교.
- 게임 시간 10초 처리에 필요한 능력치 장비 합산 계산: 7,038회 -> 414회.
- 해당 실행의 계산 처리 시간: 약 122.1ms -> 56.8ms. 이는 자동 검사 환경의 수치이며 휴대폰 FPS 개선율을 뜻하지 않습니다.
- 피해량, 적 체력, 골드, 처치 수, 예약된 공격, 효과 개수 일치.
- 처치/장비 경험치 상승 조건에서도 골드/조각/장비 경험치/피해 결과 일치.
- 검사/도적/소환술사 전투 결과도 수정 전후 일치, 브라우저 실행 오류 없음.
- JavaScript 구문 검사 통과.

실제 폴드 기기에서의 장시간 플레이 성능은 적용 후 확인이 필요합니다.
