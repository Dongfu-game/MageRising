# Mage Rising — 현재 설계

현재 버전은 v0.3.3 / Skill System 2.0이다.
게임 실행과 저장 이전은 README.txt, 실제 수치와 구현 규칙은 IMPLEMENTATION.md를 기준으로 한다.
이전 마법 10단계 개별 골드 강화/유료 진화 설계는 폐기되었다.

유지된 기반: 자동 횡스크롤 전투, 단계 n마다 n마리 무리·100n 일반 처치 후 보스,
7부위 장비·유니크 보상·선택 판매·사망 n−1 복귀·백업/가져오기.

새 성장: 무제한 마력 강화 × 지팡이 Magic ATK × 14개 액티브 스킬 계수.
기본 4계열 각각 70 SP + 초월 100 SP. 패시브 9개와 액티브 3슬롯 자동 순환.
마력/스킬트리/장비/캐릭터 4탭 UI, K부터 Dc까지 영문 대형 숫자 표기.

후속: 실제 플레이에 따른 수치 조정, 장비 합성, 강화 재료 파밍, 골드+재료 장비 강화.

v0.3.2는 초중반 일반 적/보스 HP를 고정 단계표로 보정하고 적 HP 표시와 스킬 슬롯 게이지를 추가했다. 세부 수치는 IMPLEMENTATION.md 마지막 절 참조.

v0.3.3: 기존 남성 마법사 + 신규 PNG 스킨4종, 캐릭터 탭 외형 선택, 무료 스킬 초기화. 스킨은 전투 능력치를 바꾸지 않으며 이미지 원본은 향후 패치에 그대로 재사용한다.
