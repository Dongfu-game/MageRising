마법사의 여정 v0.9.23 지도 수정 패치

설치: 기존 v0.9.21 또는 v0.9.22 게임 폴더에 같은 경로로 덮어쓰기. ZIP은 변경 파일만 포함합니다. GitHub에서는 압축을 풀고 내부 파일·폴더를 원래 위치에 업로드하세요.

수정 사항
- 발판 순서를 왼쪽 아래에서 오른쪽 위 관문까지 실제 길을 따라 재배치. 10·20·30… 마지막 단계는 오른쪽 위.
- 새 SD 해골전사·해골왕 전신 투명 이미지를 마지막 관문에 배치.
- 마법사·검사·도적·소환술사 모두 실제 인게임 리마스터 시트의 기본 캐릭터 프레임 사용.
- 같은 단계 캐릭터만 좌우 간격 조정, 선택 직업 강조.
- 페이지 전환 시 도전 대상과 선택 발판 동기화. 미해금 페이지는 도전 버튼 비활성.
- 화면 비율에 따른 지도 크기 조절과 여백 배경 개선.
- 기존 저장 데이터·전투 시스템 유지.

검증: 실제 Chromium에서 직업 전환, 전투 복귀, 잠금 진입 차단, 50/100단계 보스 이미지 로드, 페이지별 도전 대상 동기화 검사 통과. 1470×1000, 740×360, 900×740 화면 확인. 테스트 환경에는 한글 폰트가 없어 글꼴 형태는 실제 기기에서 최종 확인 필요.
