환생: 캐릭터 탭 또는 설정 → 현재 직업 환생 → 확인.
초기화: 현재 스테이지 1, 성장력 강화 0(기본 성장력), 시작 스킬만 Lv1,
투자/미사용 SP 0, 전 부위 장비 경험치 0, 시작 골드.
유지: 장비 옵션과 수치, 돌파 특성, 카드, 외형, 역대 최고 단계,
다른 직업 진행, 누적 통계, 기존 보관 유니크 상자.
이번 회차 최고 도달 스테이지는 1로 초기화.
유니크 상자 보상 = floor(이번 회차 최고 단계 / 100).
사망으로 단계가 내려가도 이번 최고 기록으로 보상.
연속 클릭으로 보상 중복 지급되지 않음. 새 회차가 100 미만이면 보상 0.
환생 직전 저장은 직업별 백업. 설정의 '환생 전 백업'으로 내보낼 수 있음.
저장 실패 시 환생/상자 소비를 중단하고 기존 데이터 유지.

장비/스킬 재성장:
회차마다 보스 최초 처치로 SP를 다시 획득.
역대 최초 보스 카드 보상은 다시 지급하지 않음.
이미 보상받았던 10단계 보스: 부위마다 기존 옵션 중 하나의 수치 증가.
옵션 종류/개수 추가 없음. 옵션이 하나도 없는 부위에 새 옵션을 만들지 않음.
이미 보상받았던 100단계 보스: 위 증가 후 기존 옵션 전체 ×2.
동일 회차의 반복 처치로 위 보상은 다시 지급되지 않음.
돌파 특성(모든 배운 스킬 +1)은 기존 값 유지,
새로운 100단계 구간 최초 돌파에서만 추가 획득.
새롭게 도달한 10단계 보상은 기존의 최초 옵션 규칙 적용.

유니크 상자:
캐릭터 탭/설정에서 1개씩 개봉.
기본 유니크 조각 10개, 각 부위 1/8 확률, 장비 경험치로 즉시 흡수.
카드의 추가 조각/조각 경험치 보너스 적용.
개봉 전까지 장비 경험치로 자동 전환되지 않음.

검사:
피해가 있는 공격 액티브의 쿨타임 0, 시전시간 유지.
막기/반격은 기존 장착 패시브 유지, 절대방어 쿨타임 유지.
성공한 타격 묶음마다 최대 HP 회복:
베기 0.5%, 찌르기 0.75%, 내려찍기 1%, 반격/초월 0.5% 기본.
적용 스킬 레벨당 +0.025%p(2레벨부터), 장비 흡수 추가.
타격 묶음당 최대 2%, 모든 스킬 합산 초당 최대 4%.
범위 공격의 대상 수만큼 회복하지 않음. 빗나가면 회복 없음.
도적 흡수는 기존 유지.

해골마법사:
한 마리 유지. 마법사 마법 디자인을 그대로 사용.
기본 전용 공격 주기 1.6초에 소환수 공격속도 적용.
마법사 스킬 쿨타임과 독립. 시전하는 마법이 바뀌어도 같은 주기로 발사.
사망 후 재소환 쿨타임은 별도 유지.

HP/카드 합산/단계 보정 등 기존 v0.9.6 규칙 유지.
검증: 2251개 로컬 검사 통과. 네 직업 환생/저장 왕복/상자/반복보상,
저장 실패 롤백, 흡수 상한과 실제 타격, 해골마법사 공격 루프 포함.
실제 휴대폰 화면 검사는 별도.
