MageRising v0.9.10 — 사망 후 5초 자동 재시작

기존 v0.9.9에 같은 경로로 덮어쓰기:
index.html
sw.js (루트)
js/game.js

사망 팝업에 5초 카운트다운 표시 후 자동 부활.
기존처럼 한 단계 뒤에서 HP를 회복하고 전투 재개.
'지금 다시 시작' 버튼으로 즉시 부활 가능.
수동 부활 후 이전 타이머는 취소되어 중복 부활/단계 감소 방지.
직업 전환/환생/세계 초기화 시 이전 타이머 폐기.
죽은 상태로 재접속하면 새 5초 카운트다운 시작.
브라우저가 백그라운드 타이머를 늦추면 복귀 후 처리될 수 있음.

사용자가 수정한 HP 보정 유지:
1 + max(0, floor(스테이지)-10) ×0.1.
저장/장비/스킬/카드/골드 변경 없음.

검증: 기존 회귀 검사와 가상 시계 타이머 검사를 포함해 6025개 통과.
5초 경계, 수동 부활 취소, 연속 사망, 직업 전환, 재접속 포함.
