1. 일반 적 HP
1단계 HP 100.
1→2부터 9→10까지 단계당 +100.
10→11부터 19→20까지 단계당 +110.
20→21부터 29→30까지 단계당 +121.
1:100 / 10:1000 / 11:1110 / 20:2100 / 21:2221 / 30:3310.
적 HP 전체를 매번 곱하지 않고 증가량을 10단계마다 ×1.1.

2. 성장력
기본 성장력 10. 강화 1~10회는 회당 +1.
11~20회 +1.1, 21~30회 +1.21.
강화 10레벨:20 / 20레벨:31 / 30레벨:43.1 (장비·카드 제외).
강화 비용은 기존 유지.

3. 모든 직업 공격 공식
기본 공격력 = 성장력 + 무기 공격력 + 카드 공격력.
피해 = 기본 공격력 × 스킬 배율 및 레벨 보정.
기존 스킬 시너지·패시브·치명타·저항·방어 판정 유지.
마법사/검사/도적/소환술사 모두 같은 합산 규칙 적용.
장비 자체의 레벨 성장 곡선과 100단계 옵션 ×2 보상은 변경하지 않음.

4. 카드
공격 관련 기존 1% → 고정 공격력 +1로 환산.
성장력·무기·전체 피해 카드는 각각 고정 수치로 합산.
보스/일반 적 전용 카드는 해당 대상에만 고정 공격력을 더한 효과.
별 성장·라인 보너스에도 같은 환산 적용.
치명타·공속·HP·방어·골드·조각 같은 카드는 각 능력치 합산 방식 유지.
카드 보유/별/미개봉 데이터 유지. 퍼센트 표시도 실제 단위로 수정.

5. 보스
기존 후반 가속 HP 공식과 보정표 사용 중단.
일반 적과 동일 성장 곡선 ×10 (config.js의 bossHealthMultiplier).
10단계 동시 보스, 해골전사·해골왕, 왕의 호위 소환은 기존 유지.
보호막·적 방어·공격력·골드 곡선은 이번 변경에 포함하지 않음.

6. 저장
진행·강화 횟수·장비 경험치·스킬·카드는 초기화하지 않음.
기존 강화 횟수에 새 수치를 재계산하므로 표시 공격력/DPS가 크게 달라질 수 있음.
직업 저장 원본은 최초 읽기 시 pre-v095-backup 키로 자동 보관.
업데이트 전 설정에서 저장 파일도 내보내기 권장.

검증: 2052개 로컬 검사 통과. 1~1000단계 HP 점화식, 경계값,
네 직업 공격, 카드 합산/표시, 저장 검증, 보호막 초과 피해 포함.
실제 플레이에 따른 처치 시간 균형은 추가 조정 가능.
