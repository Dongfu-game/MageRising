MageRising v0.9.9 — 하단 카드 메뉴 줄바꿈 수정

기존 v0.9.8에 아래 파일을 같은 경로로 덮어쓰기:
index.html
style.css
cards.css
sw.js (루트)

원인: 다섯 개 버튼이 네 칸 그리드에 배치되어 카드 버튼이 다음 줄로 밀림.
전투/스킬/장비/캐릭터/카드 모두 다섯 개 균등 열, 한 줄로 배치.
좁은 화면에서도 버튼 최소 높이 때문에 메뉴 바 밖으로 밀리지 않도록 수정.
메뉴 바 위치와 기존 화면별 크기 유지.
CSS URL 및 서비스워커 캐시 갱신.
저장/밸런스/카드 추첨/환생은 변경하지 않음.

확인: HTML 버튼 개수, 다섯 열/한 줄 선언, 최소 크기, 캐시 버전.
실제 휴대폰 화면 확인은 별도.
