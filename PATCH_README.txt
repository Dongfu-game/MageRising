MageRising v0.9.8 — 완성 카드 추첨 제외

v0.9.7에 다음 파일을 같은 경로로 덮어쓰기:
index.html
sw.js (루트)
js/cards.js
js/game.js

총 32장 보유 = 5성 완성 카드는 추첨에서 제외.
등급 내에서는 미완성 카드만 균등 추첨.
등급 전체를 완성하면 그 등급도 제외하고, 남은 등급의 기존 확률 비율로 재분배.
예: SSS 전체 완성 시 SSS는 나오지 않으며 다른 미완성 등급에서 추첨.
보스/기존 미개봉의 확정 카드가 완성이면 같은 등급의 미완성 카드로 대체.
해당 등급도 완성이면 남은 등급에서 추첨.
여러 장 동시 개봉도 한 장마다 최신 보유 수량을 반영하여 5성 즉시 제외.

36종 전부 5성이면 남은 개봉분은 카드 없이 1장당 1포인트로 전환.
전 카드 완성 시 포인트 뽑기는 비활성화하여 포인트 낭비 방지.
기존 카드·별·미개봉·포인트·보스 보상 기록은 유지.
장비/환생/캐릭터 진행은 변경하지 않음. 데이터 초기화하지 않음.

검증: 기존 회귀 검사 포함 5969개 로컬 검사 통과.
각 완성 카드 제외, 등급 완성, 확정 카드 대체, 일괄 개봉 중 완성,
전체 완성 화면/포인트, 저장 실패 시 원본 유지 포함.
