Mage Rising — 대표 50마리 군집 실드 테스트판 v1

이 파일은 본게임 덮어쓰기 패치가 아닙니다.
기존 v0.9.28 게임 폴더에 ZIP의 새 파일을 추가하세요. index.html은 바꾸지 않습니다.
GitHub Pages에 추가한 뒤 아래 주소로 실행:
https://dongfu-game.github.io/MageRising/swarm50-test.html
로컬 실행은 기존 게임 폴더의 swarm50-test.html을 여세요.
기존 CSS/이미지/공용 JS를 사용하므로 ZIP만 별도 빈 폴더에 풀면 실행되지 않습니다.

실행
1. 테스트 설정에서 단계와 성장력 강화 값을 선택하고 '선택 단계로 새 실험'을 누릅니다.
2. 실제 캐릭터 조건으로 비교하려면 '현재 본게임 캐릭터 복사'를 누릅니다.
   같은 웹 주소에 저장된 현재 직업을 읽기만 합니다. 없으면 설정에서 백업 가져오기를 사용하세요.
3. 실험 기록은 별도 저장됩니다. 본게임 캐릭터/카드 기록은 변경하지 않습니다.
4. 테스트 설정 버튼으로 다시 단계를 바꿀 수 있습니다.

확정 규칙
- 한 스테이지의 대표 일반 적 총수 = 50마리.
- 각 대표의 겹수 = (단계×100)÷50 = 단계×2.
- 1~10단계 동시 1마리, 11~20단계 10마리, 21~30단계 20마리,
  31~40단계 30마리, 41~50단계 40마리, 51단계 이후 50마리.
- 죽어서 빈자리가 생기면 남은 대표를 충원합니다. 총 50마리 이후 충원하지 않습니다.
- 한 겹은 기존 일반 적 1마리의 HP+방어막입니다. 초과 피해는 다음 겹으로 이월합니다.
- 여러 겹이 깎여도 전투 개체는 늘지 않으며, 산술식으로 소진 겹수를 계산합니다.
- 소진 겹수만큼 처치 수/골드/장비 조각/일반 카드 드롭 기회를 반영합니다.
- 조각 등급·부위 추첨은 기존 방식으로 해당 수량만큼 처리합니다. 피해 판정은 겹별로 반복하지 않습니다.
- 상태이상/공격은 대표 하나 기준이며 다음 겹에도 남은 상태이상이 유지됩니다.
- 보스 및 보스 소환병은 50 일반 적 제한에서 제외하고 기존 규칙을 사용합니다.
- 본게임 복사/일반 백업 가져오기는 해당 단계의 전투 진행을 0부터 다시 시작합니다.

검증
- 1/10/11/21/31/41/51/100/113/121/150/200단계 대표 수·동시 제한·총 처치 목표·조각 수량.
- 초과 피해로 3겹 소진 후 다음 겹 50% HP 유지 및 재접속 복원.
- 원본 캐릭터 및 공용 저장 키 변경 없음, 브라우저 실행 검사.

실험 범위
- 발열/FPS 개선은 실제 폴드에서 비교해야 합니다. 상한 54→50 자체의 감소는 작습니다.
- 광역기의 전체 처리 효율·상태이상 효율·적 공격 총량이 기존과 다를 수 있습니다.
- 단계별 보스 밸런스는 확정 전입니다. 드루이드·상점 개편은 포함하지 않았습니다.
