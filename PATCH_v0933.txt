MageRising v0.9.33 — 총사 신규 직업 추가
2026-10-22

[적용]
1. ZIP을 풀고 안의 index.html, sw.js, gunner.css, js/, assets/를
   기존 게임의 같은 경로에 덮어씁니다. 기존 js/assets 폴더 자체를 삭제하지 마세요.
2. GitHub에는 ZIP 파일을 올리는 것이 아니라, 압축 안의 파일들을 경로대로 업로드합니다.
3. 배포 완료 후 게임을 새로고침하고, 여정 지도에서 다섯 번째 직업 '총사'를 선택합니다.
4. 설정의 버전 표기: v0.9.33. 브라우저 게임 저장 데이터는 지우지 마세요.

v0.9.28~v0.9.32용 누적 변경 파일 패치입니다. 단독 실행하는 전체 게임은 아닙니다.
이전에 검사 이펙트/회오리/관통일섬 패치를 하지 않았어도 해당 변경 파일을 포함합니다.
이 ZIP을 만드는 과정에서 GitHub 커밋/푸시 또는 실제 사이트 배포는 수행하지 않았습니다.

[직업]
기존 마법사, 검사, 도적, 소환술사 유지. 총사만 별도 직업으로 추가.
소환술사의 장비/SP/외형/진행을 변환하지 않습니다.
총사 성장/스킬/장비/진행/탄약은 별도 저장. 카드 수집은 기존처럼 공용입니다.
새 총사에 기존 직업 보유 골드/강화레벨/장비를 복사하지 않습니다.

[총사 전투]
속사/저격/포격 고정 자동 사격. 세 종류를 처음부터 함께 사용.
시작 탄창20발, 강화1레벨도20발, 이후 강화1레벨마다+1발.
속사1발, 저격1발, 포격2발. 자탄/엑스칼리버 습득 시 포격 소모 각+1발.
탄약0 자동 재장전. 기본2초, 급탄 특성으로 최소1.2초.
잔탄1발일 때 포격은 대기하고 저격/속사가 소모합니다.
하단 세 공격을 눌러 교체하는 방식이 아닌, 스킬창에서 특성을 강화하는 방식입니다.
각 공격 타이머는 독립. 포격/저격/속사가 동시에 준비되면 이 순서로 탄약을 사용.
탄창/장전/각 사격 대기시간/초월 충전을 저장합니다.

[스킬]
속사 → 저격 → 포격 → 급탄 → 초월. 총380SP.
일반 계열 각70SP, 초월100SP. 첫1SP는 M855A1 Lv1.
탄종9종과 부품/급탄 특성은 배운 효과가 누적 자동 적용됩니다.
성장레벨 조건과 선행 특성 조건은 기존 트리 구조를 따릅니다.
초월은 기본 네 계열을 모두 최대 투자하면 열립니다.
확장 탄창/탄띠는 최대 수량을 늘리며 현재 탄약을 공짜로 채우지 않습니다.
늘어난 수량은 다음 재장전부터 채워집니다. 골드 강화로 수량이 늘면 새 칸만 즉시 추가.

[초월]
Nuclear: 기본 사격30회마다 추가 핵폭발.
농축: 핵폭발의 피해/반경 강화.
전술폭격: 습득 후 기본 사격300회로 충전, 직접 버튼을 눌러 사용.
포격이4발을 써도 충전1회. 관통/자탄/핵폭발/폭격은 충전 재발동 없음.
충전 완료는 자동 사용하지 않습니다. 준비된 폭격은 재장전 중에도 사용 가능.
폭격은 사용 시 존재하던 공격 가능한 적에게만 40/30/30%로 나눠 타격.
새로 나오는 무리는 해당 폭격의 대상에 포함하지 않습니다.

[이미지]
성인 여성5스킨 × 대기/견착/사격/반동4프레임. 스킨 능력치 동일.
속사/저격/포격 투사체3종. 원본 PNG를 런타임에 잘라 사용합니다.
탄약 바/전술폭격 버튼은 상단 정보 아래에 배치하여 골드와 겹치지 않게 했습니다.
