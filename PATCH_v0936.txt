MageRising v0.9.36 — 속사 파편 원형 범위 공격

적용 대상: 총사 추가를 적용한 v0.9.33~v0.9.35.
ZIP을 풀어 index.html, sw.js, js/gunner.js, js/gunner-data.js를
기존과 같은 경로에 덮어쓰고 새로고침합니다. 새 이미지 파일은 필요 없습니다.
이 파일 제공까지 완료했으며 실제 사이트 배포는 수행하지 않았습니다.

M995 AP 파편탄 변경:
- 전방 부채꼴에서 최대3~6명을 고르던 제한 제거.
- 원탄 적중 지점 중심의 원형 범위 안에 있는 다른 적 전부를 타격.
- 원탄 대상 제외. 좌우/전후 방향 제한 없음. 공격 가능한 화면 내 적 대상.
- 각 대상에게 원탄 기본 피해의25%. 각 대상 방어/속성 저항/보스 보정 적용.
- 파편의 추가 치명타/표식/방어 무시/재분열/중복 타격 없음.
- 탄약 소모와 초월 충전은 여전히 원탄 발사1회로 계산.
- 반경 Lv1=120, 레벨당+10, Lv10=210. 장비 범위 보너스 적용.
- 기존 M995 AP 원탄 방어 무시 최대20% 유지.
- 파편 그림 수3~6개는 시각 효과용이며 타격 대상 수에 영향을 주지 않음.
- 저효과 모드에서도 범위 내 모든 대상에게 같은 피해 적용.

직선 탄도/작은 반동/고정 견착 자세는 앞선 수정 포함.
기존 저장/SP/장비/재장전/저격/포격 수치는 유지.

검증:
실제 총사 모듈을 결정적 게임 API 환경에서 실행한18항목 통과.
100마리 중 원탄 대상 외99마리 타격, 방향/개수 제한 제거,
원탄 제외, 원형 경계/범위 밖 제외, 피해25%, 방어 적용,
재귀 방지, 충전/탄약1회, 미습득/저효과 모드,
기본3공격 수치 및 저장 형식의 v0.9.35 일치 확인.
이번 검사는 모듈 실행 검사이며 실제 폰 발열/FPS 검사는 아닙니다.
