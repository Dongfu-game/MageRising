# 마법사의 여정 v0.9.1

8부위 자동 장비 성장: 일반 적과 보스의 조각을 해당 부위 경험치로 즉시 흡수합니다. 10단위 최초 보스로 전 부위 옵션 추가, 100단위 최초 대보스로 추가 옵션 전체2배와 배운 모든 스킬+1(패시브·초월 포함)을 얻습니다.

기존 진행은 직업별로 자동 이전합니다. 기존 착용 능력치·고유 능력·세트 효과와 카드 도감을 유지하며, 미착용 장비와 보관 보상은 경험치로 전환합니다. 설정에서 현재 백업과 개편 전 원본 백업을 내려받을 수 있습니다.

## 실행과 업로드

- 웹 실행: index.html을 여세요. GitHub Pages는 전체용 ZIP 내용물을 폴더 구조 그대로 업로드합니다.
- 이미 v0.9.0이 있다면 Update ZIP 내용을 기존 파일에 덮어쓸 수 있습니다.
- 새 필수 파일은 auto-gear.css와 js/auto-gear.js입니다.
- sw.js는 루트에 하나만 사용합니다. 예전 js/sw.js가 있으면 삭제해도 됩니다.
- 업데이트가 보이지 않으면 앱을 완전히 닫았다가 다시 여세요. 버전 표시는 v0.9.1입니다.
- START.html은 대용량 단일 파일이므로 GitHub용 ZIP에는 포함하지 않습니다.
